# МР17дом1

Исходные файлы информационного сайта [ТСН «МР17дом1»](https://mr17dom1.ru).
Сайт содержит сведения о товариществе, полезные контакты и ссылки на документы.

## О проекте

Сайт основан на статическом экспорте Tilda. Страницы, стили, скрипты и
изображения хранятся в репозитории. Для локального просмотра не нужны
Node.js или база данных.

Некоторые ресурсы загружаются с внешних сервисов, поэтому для полного
отображения требуется интернет. Форма обратной связи пока не подключена.

## Структура

- `mr17dom1-from-tilda/page56734223.html` — главная страница.
- `mr17dom1-from-tilda/css/` — стили.
- `mr17dom1-from-tilda/js/` — скрипты.
- `mr17dom1-from-tilda/images/` — изображения и иконки.
- `scripts/check-site.py` — проверка локальных ссылок на ресурсы.
- `scripts/smoke-test.sh` — HTTP-проверки контейнера.

## Локальный запуск

Понадобится Docker. Выполните из корня проекта:

```bash
docker build -t mr17dom1-site:local .
docker run --rm -p 127.0.0.1:8080:80 mr17dom1-site:local
```

Откройте [localhost:8080](http://localhost:8080). Для остановки нажмите `Ctrl+C`.

## Редактирование

Изменяйте главную страницу и связанные с ней ресурсы. Сохраняйте имена
файлов экспорта, чтобы не нарушить ссылки на стили, скрипты и изображения.
Файл `files/page56734223body.html` — служебный фрагмент экспорта;
он не является основной страницей.

Для нового экспорта Tilda замените содержимое `mr17dom1-from-tilda/`.
Если имя главной страницы изменилось, обновите настройку `index` в
`deploy/nginx.conf` и проверку в `scripts/check-site.py`.

## Проверка изменений

Для проверки ресурсов требуется Python 3.9+, для HTTP-проверок — Docker,
Bash и curl:

```bash
python3 scripts/check-site.py
docker build -t mr17dom1-site:test .
bash scripts/smoke-test.sh mr17dom1-site:test
```

Перед отправкой изменений проверьте отображение страницы в браузере.
В pull request кратко опишите изменения и выполненные проверки;
для изменений внешнего вида приложите скриншоты.
